# MODEL 2.9 — Render QA

### 图像生成前后核验
- [ ] 同一辆真实比例的 2024+ M3 Performance Highland；完整侧视、车轮、门缝、车顶、C 柱和轮拱可信。
- [ ] DAY 和 NIGHT 是同一套 decal 和同一车身几何；红色/T/反光主线位置一一对应。
- [ ] **画面所写 VERSION 与实际迭代编号一致**。#26 画面曾误写 VERSION 25；除非保存一个明确标记的衍生修订版，否则绝不覆盖原图。
- [ ] NIGHT 全部预设反光部件严格**同色、同亮度、无明暗渐变**；T 密度变化来自离散标志数量/间距，而不是暗淡半显影。
- [ ] DAY 中黑色反光材料不被画成银白车贴。
- [ ] NIGHT **FULL REVEAL** 同时完整显现全部反光图形，不靠光线角度或暗部隐藏拥挤。
- [ ] 即使在 NIGHT 全显影下仍有真正的黑色负空间，主次清晰，没有 #18 的鬼火感。
- [ ] 线条沿真实造型曲面，类似汽车手稿，并保持性能张力；不是 LED 灯带、GT 多条平行装饰线或 Z 框。
- [ ] 后轮拱和 C 柱的结构被巧妙突出，但不会变成轮拱亮弧、红线、T 同时抢戏。
- [ ] 主色块到 Tesla T 的过渡足够长，T 细且自然渐隐，不是贴上明显矩形的 Logo 墙。
- [ ] 红色有明确工程式角色，数量克制，不用三斜杠和无意义三角。
- [ ] 视觉依赖纯实色简单形状，不靠 mesh/perforation/磨砂噪点、无数异形小碎片。
- [ ] 说明夜间为审美压力测试、贴膜材料和施工均未验证。
