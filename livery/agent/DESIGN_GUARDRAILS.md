# MODEL 2.9 — Design Guardrails

## 车本体
**2024+ Tesla Model 3 Performance Highland**，现有哑光黑 Apterix PPF；仅加第二层。不要把其他 Model 3 年款的形体当原车。产品身份 `MODEL 2.9` / `EVT-2.9-0001` 是艺术性的原型标记，不是假冒厂家真实认证。

## 同一 decal 的 DAY 和 NIGHT FULL REVEAL
- DAY：黑反光膜仍是黑/近黑，可辅以少量红色；不出现巨型浅银白图形。
- NIGHT：**所有原定反光部分同时显著显影**，进行最坏审美密度压力测试，不允许通过选择性光照把过满遮起来。
- **2026-10-12 用户加严：所有反光图形必须统一等亮，不允许同一反光材料的亮度/颜色渐变、模糊半亮、尾部渐暗。** 视觉密度渐变只能通过离散图形的数量/间距变化实现，不能通过反光强度过渡作弊。真实材料角度依赖另行测试。
- 同一车辆、同一侧面视角、同一条线和 T 纹理布局，不能日夜生成两套图案。真实材料反射仍未验证。

## 汽车设计手稿风格
- 优先 **1 条有曲率张力的主肩线 + 1 条局部且弱得多的体块次线**；避免多层平行 GT pinstripe、Z 形框线、汽车周身 LED 灯条。
- 顺真实肩线、门下方折线/侧裙、车顶到 C 柱的走向、后轮拱外扩肌肉与后翼子板运动方向。局部有明显收紧、渐尖、自然断开，但不是又硬又碎的几何闪电纹。
- **用户针对 #20 的新反馈（2026-10-12）：主线偏软。** “汽车手稿”不等于均匀柔顺的丝带；要学习赛道超跑的 *sculpted tension*：长弧中的快速曲率变化、明确力点、厚薄对比、突然收尖、局部断点。不能矫枉过正变成锐利 Z 字折线、硬闪电或多条平行 GT 线。
- 以 AMG、Aston Martin、Bugatti、Pagani 的真实赛车和概念车为**分析参考，而非照抄拉花/颜色/标志**。应区分实体气道/碳纤/车身表面、分色漆面和贴花；Model 3 不存在的风道不能凭空画。
- [具体参考与 #21 草案](../research/2026-10-12-performance-line-language.md)。
- 某处因全亮太突兀，要删改实体图形而不是偷偷调暗渲染。

## Tesla T 视觉语法
- 覆盖可扩至后门和后翼子板，单体依旧微小。近看是 T，远处为高性能车的精致肌理。
- 与主图形长距离融合：主线还没结束时 T 就渐增，主线收窄/分叉为少量实色单元，再由细小 T 接管，向车尾自然消散。不是旁边贴一块整齐的矩形 T Logo 墙。
- **施工假设**：T 的可切尺寸需验证；不能靠 mesh、磨砂孔洞、无限细小碎片或印刷噪点产生视觉幻觉。

## 红色和留白
- 红色允许更明确，但只能用于原型工程参考/流线起点/转换节点/对位/少量编号等可解释设计语言；避免随机斜杠、三角和装饰点。
- 视觉留白必须是真正的黑色静区，不是上下明亮线条框住的前门。夜间 FULL REVEAL 也要干净而有性能感。
- 若亮弧、T 和红色在轮拱同时抢戏，删掉其中元素。

## 官方实验原型车审美（用户 2026-10-12 明确核心衡量）
- 首要标准是**视觉上可信的 Tesla 自主设计实验原型车**，不是套上 AMG/Pagani 风格的 Model 3，也不是贴满刀锋的机甲街头改装。
- 在用户现有的哑光黑 M3P 和红色 Performance 刹车卡钳之上，新增色彩必须有功能身份与极高主次对比。助手建议：黑色基体、非主导性的深钛灰结构形状、1–2 个 Performance Red datum。**仅为 #24 提案，未经用户核准，不是强制已批准的选色。**
- 真正力量感来自真实车身 / aero 件承力结构感、体积变化与短促收紧，不来自堆叠刀片、Z 形切面或赛车贴花。
- 与现有轮拱、侧裙、尾翼/后唇等装备几何相呼应；用户旧照片未重新提供时不能冒充已核对具体 aftermarket 件形状。
- `MODEL 2.9` 和 `EVT-2.9-0001` 是私人概念车代号，不得假称 Tesla 官方项目或真实认证。
