# MODEL 2.9 — 全部 AI 渲染轮次与反馈归档

**范围：** 2026-10-11 至 2026-10-12 的本段对话中，从代码优先切换为图像生成优先之后的探索、用户审美反馈、工程可行性意见和当前已确认约束。对应原图参见 [渲染索引](README.md)。保留之前 [V1](../0001-2026-10-11-ghost-reflective/)、[V2](../0002-2026-10-11-ghost-aerodynamics/) 与 [V3 G0](../0003-2026-10-11-track-kinetics/g0/) 原始文件。

## 阶段 0：原项目起点（已确认）

- 实车：2024+ Tesla Model 3 Performance，已有**哑光黑 Apterix PPF**，在原 PPF 上加第二层纹理/贴膜，不整车重新改色。
- 产品身份：`MODEL 2.9`，技术编号 `EVT-2.9-0001` 可作为辅助原型身份。不是厂商真实试验车声明。
- 目标：白天低调近黑；光照下黑色反光材料“显影”；偏精细纹理，不能变成大片醒目的白色赛车贴纸。
- 三种设计语言原本分别为 Aero Flow／Parametric Fade／Blueprint，后来要求合为一套；T 符号纹理受 AMG Motorsport Collectors 式重复品牌符号启发，但不直接复制 AMG 图案。
- 2026-10-11 前的 V1/V2：长而平行的线条显得豪华 GT，非运动；手绘侧视车身不准确。V3 开始寻求真实 M3P 几何。
- 用户主动调整流程：**先通过图像生成工具锁定审美方向，再用代码/UV/施工图反向拟合**。暂停 G0 的代码优先方法。这个选择避免先工程化错误的视觉方案。

- 比较剪切运动结构 A、Tesla T 品牌微纹理 C 和较碎裂的 B。
- 用户指出：**日间的“白色”反光图形实际上应该是黑色／近黑色材料，不能在 DAY 状态就显示银白。** 若加入红色，需要区分日间实红与夜间强调红。

## 阶段 2：Fusion 与可施工性（11–14）

**[11 A+C Fusion](renders/11_A_plus_C_fusion.png)** — 首轮融合。
- 用户认为它**更接近 B+C 而非 A+C**：过多碎块、微纹理和渐变斑点，没有清晰运动主结构。
- 用户指出很多破碎图案内部并非实色，若要用微孔/mesh 模拟磨砂幻觉，复杂到不可接受；微孔排废、贴合曲面和耐久性都成为工程障碍。
- 决策：**尽量用独立的实色形状＋纯黑反光膜＋少量红色标识；不用大面积细孔 mesh 或印刷磨砂幻觉**。

**[12 Constructible A+C](renders/12_constructible_A_plus_C.png)** — 强调实色切膜、独立 T 元素。
- 优点：主构图开始从碎裂纹理变成有控制的剪切结构，施工概念更合理。
- 不足：仍容易太满、切片多、T 排列机械。

**[13 Ridge Guided Reveal](renders/13_ridge_guided_reveal.png)** — 用户补充最初重要原则：夜间反光纹路必须**利用车身真实脊线**，不只是画大致顺车身方向的条带。
- 要关注机盖力量线、肩部体块、门下折线/侧裙、后轮拱、后翼子板、C 柱和车顶下降线；关键反光元素要说明它沿着哪一条真实曲线。
- 反光的任务是**勾勒 M3P 的形体与姿态**，而不只是独立亮起来。

**[14 Solid-Cut / Functional Red](renders/14_solid_cut_functional_red.png)** — 摒弃磨砂质感和浮夸碎片。
- 用户要求：实色可施工，同时红色不应只是点缀。尝试让红色表示 reference datum、流线起点、转折点、过渡节点或视觉方向。
- 用户批评：虽更可落地，但反光线依然像人为加的贴纸，没有真正准确依附实体车身；红色三斜杠、三角形像泛化改装车符号。
- **注意：** 红色“定位/导引”属于虚构原型车视觉编码，不代表真实 Tesla 工程标识。

## 阶段 3：负空间、AMG 式长过渡与车身轮廓（15–17）

**[15 Sparse Ridge Texture](renders/15_sparse_ridge_texture.png)**。
- 用户反馈：有的前一轮图**过满、留白不够、碎片化失去线条感、T 与色块边界太硬、T 单体太大无法呈现纹理感**。
- 新要求：前中部保留足够黑色静区，主结构少而有力；T 的覆盖区可以增大但**每个 T 更小、分布更密**。
- 从色块到 T 不是两块相邻区域，而是**连续完整图形 → 边缘被小单元侵蚀／收束 → 小单元逐渐呈现 Tesla T → T 场扩散消散**。以渐变的图形逻辑参考 AMG，不能把大面积 mesh 重新带回施工。

**[16 Ridge Transition v2](renders/16_ridge_transition_v2.png)**。
- 用户提出：轮拱与车顶／C 柱线条也该参加设计，不能只有车门腰线；可增加连续主色块覆盖区，使与微纹理转场不那么生硬。
- 红色可**更大胆**，但必须承担明确的视觉方向或工程参考职能。
- 评论：生成版本虽然视觉完整，有时变成过大的 Z 形两条长平行框架；T 纹理仍像单独贴在后翼子板；红色仍显可有可无。

**[17 Design Sketch Contour](renders/17_design_sketch_contour.png)**。
- 用户明确指出某版过硬的反光条与车体违和，参考**汽车设计师手绘草图**中沿车身力量线勾勒体块的自然曲线。
- 好的风格是柔顺的大趋势 + 关键位置更强曲率张力，不能所有线都豪华 GT 式丝滑；同时不能重回尖锐碎片“鬼火风”。
- 实际设计中要尊重真实 M3P 曲面，AI 侧面轮廓与贴膜轨迹仍需要后续验证。

## 阶段 4：减法、最坏照明验收与近期基线（18–19）

**[18 Sculpted Velocity](renders/18_sculpted_velocity.png)**。
- 用户评价“**有点太满了，有点鬼火感**”。
- 审美复盘：一个版面里有太多同时强调速度的亮条、C 柱线、轮拱弧、红色小斜杠和满布 T，夜间像 LED 轮廓灯。
- 删除多余并列线和无功能的红三道杠/三角，后轮拱红色与 T 不应互相争抢。

**[19 Ghost Sculpture / Full Reveal](renders/19_ghost_sculpture_full_reveal.png)** — 当前最接近用户要求的**审美参考基线**，不代表已经最终批准。
- 更克制：一条有曲率张力的主肩线，次级下部体块线，一片从主线逐渐转入的细微 T 纹理。
- 不因夜间图过亮而“作弊”隐藏一些反光段。用户明确要求保留原来**全车反光图形同时显现的夜间效果，作为最坏视觉情况（Night Full Reveal）**。
- 因实际黑色反光材料的入射角、观察角不一致，所有部位同时高亮是一个**刻意偏严的审美压力测试**，不是实际单个车灯照射下精确物理预测。
- 之前初评这版在克制感、肩线与负空间上有进步，但 T 过渡仍有可改空间，红色功能参考点仍未形成稳定规则。

## 现阶段有效原则（以用户明确确认的意见为准）

1. **现有哑光黑 PPF 为基底**；白天反光图层必须接近黑色，不能像银白贴纸。
2. 夜间 **FULL REVEAL** 是必须保留的密度压力测试，反光材质的真实亮度仍需小样。
3. **实色材料与可施工形状优先**；避免不可控的磨砂斑点、网状挖孔和数不清的极小孤岛贴纸。Tesla T 的极限尺寸需实物试切。
4. **先形体，后纹理**：主线真实贴合机盖／肩线／下部门板／轮拱／车顶 C 柱等车身特征，不能把摄影灯光当设计贴膜。
5. 有车身曲率张力、少量强弱变化且主次清楚的**汽车设计草图式线条**，但不回到大量等间距的优雅 GT pinstripe。
6. **大范围微型 Tesla T、没有边界清晰的“贴纸区域”**；从主结构逐渐转入符号纹理。T 的官方/可追溯 SVG 已放在 [../assets](../../assets/README.md)（使用前仍须核验形状与商标使用）。
7. 留白是真留白：不能通过一条上反光线和一条下反光线把整扇门“包起来”，造成视觉上始终不安静。
8. 红色可以更明确，不要求越少越好；要用来**标定基准、转换或方向**，而非任意三斜杠装饰。
9. `MODEL 2.9` / `EVT-2.9-0001` 是有限次数出现的工程身份标记，不铺满广告文案。
10. **审美先定、代码后拟合**；G0 仅是初级照片参考轮廓，准确 M3P 左右车身 3D/UV 面板仍未验证。未经验证不输出 1:1 切膜 SVG/DXF。

## 尚未确认／不能当作事实的内容

- 背后黑色逆反射膜的具体色、夜晚“白亮”程度及曝光角度；白天是否在哑光基底上产生光泽反差。
- 哪一家材质和胶是否与 Apterix matte PPF 化学/长期兼容；贴膜边缘寿命与去除难度。
- 实车的精确 M3P 几何及用户后期加装件是否影响包围/后扰流板贴膜空间。
- 内部挖孔、大量微型 T 的裁切时间、成功率、洗车耐久与单次更换成本。
- 红色在真实物料上具体使用深红、亮红或夜间红反光；交通法规和安全可视要求。
- **图中有些 T Logo、文字和车身结构由 ImageGen 合成，不能直接机械描摹并用于生产。**

## 继续研究时的建议流程

先用图像生成对“当前 19 的克制”和“15 的纹理密度”进行**同一车身、相同日间/全显影夜间的严格对比**。审美确定后再通过已存储的 Tesla T SVG、带几何来源的车体参考和材料小样，将线段分配到实际面板并输出 Paint Shop 试验贴图；切膜仅在几何与实物小样核验后进行。避免在用户审美尚未稳定时反复代码重写。
