# V3 acceptance gates — Track Kinetics

**Planning status:** all content below is proposed criteria, not proof of a completed stage.

## Must pass before any V3 livery image is considered a serious candidate

- [ ] Calibrated M3P blank base accepted (2024+ Performance, recognizably correct roof/hatch/hood, true wheel-arch voids, fenders, light locations, side window lines, 20-inch wheels / Performance styling reference).
- [ ] Wheelbase, length and height matched to factory approximate specs; contour/source origin recorded.
- [ ] Three candidate artwork directions all drawn over **the identical** calibrated base.
- [ ] No more 2–4 principal *gesture groups*; broken texture/particles can comprise many small elements but must not imply many parallel full-length luxury pinstripes.
- [ ] Motion emphasis produces directional tension and asymmetry without large opaque race stripe blocks.
- [ ] Real Tesla T vector reference imported; no homemade approximations or stretched symbols.
- [ ] Close-up glyph fidelity and scale distribution reviewed; no fake T characters.
- [ ] `MODEL 2.9` has a deliberate focal zone and functional-looking annotation grammar, not random microtext.
- [ ] Simulated material views include daylight matte/gloss angle and nighttime directional light with honest labels.
- [ ] Small detail and cut feasibility remain explicitly unverified until tests.
- [ ] Left/right layout and the physical UV atlas are not conflated with a flat side-reference image.

## QA benchmark (proposal)

Compare V3 against frozen V2:
- **Track/performance impression** stronger than elegant/luxury impression in an A/B subjective review.
- **At ~5m:** the primary gesture is legible as an energetic focal element but the matte black vehicle remains dominant.
- **At ~1m:** Tesla T symbols and prototype ID can be found without feeling like continuous advertising.
- **At pixel-to-mm:** no feature passes to fabrication unless tested against actual film/weed/PPF samples.
- **3D mapping:** every major line break, rear haunch crescendo and microtype direction validated in left/right 3D Paint Shop before physical design.

**Hard stop:** A 2D image alone does not imply corrected 3D geometry, Paint Shop compatibility or a manufacturable decal set.
